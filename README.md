# Portfolio_2

A personal portfolio website built with React, Vite, and Tailwind CSS. It presents a modern single-page portfolio with sections for introduction, experience, projects, education, certifications, technologies, and contact details.

## Overview

This project is designed as a front-end portfolio site for showcasing:

- personal introduction and hero section
- work experience timeline
- project highlights and case studies
- education and certifications
- technology stack and skills
- contact information and resume download

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- PostCSS
- CSS and custom animations

## Folder Notes

- `src/components/` contains the UI sections that make up the portfolio page.
- `src/data/` stores portfolio content separately from the UI so it is easier to update text and project information.
- `src/assets/` contains local images used in the portfolio.
- `public/` holds static files such as the PDF resume and site favicon.
- `dist/` is generated automatically during production builds.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

Then open the local URL shown in the terminal, typically:

```bash
http://localhost:5173
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Summary

This repository is a React-based portfolio website designed to showcase personal branding, technical skills, professional experience, and project work in a clean and modern presentation. The structure is organized to keep content, UI components, and static assets separated for easy maintenance.
